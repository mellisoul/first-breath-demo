# First Breath — демо

Веб-демо проекта **First Breath** команды **TYNYS** (AI-Sana Startup Challenge 2026, КазНУ им. аль-Фараби).

ИИ-помощник дыхательной реабилитации дома: телефон или ноутбук слушает дыхание через микрофон, ведёт по ритму упражнения, подсказывает и собирает отчёт для врача. Интерфейс на русском и казахском.

## Что умеет демо

- Лендинг проекта: проблема, принцип работы, команда
- Главный экран в виде монитора дыхания с живой кривой
- Схема лёгких, которая расширяется и сжимается в ритме упражнения
- Три упражнения: диафрагмальное дыхание (4–6), выдох через сомкнутые губы (2–4), ровный ритм (4–1–4)
- Отсчёт 3-2-1, кольцо фазы, звуковой сигнал и вибрация на смену вдоха и выдоха
- Шкала одышки Борга (0–10) до и после занятия
- Живая кривая дыхания с микрофона
- Частота дыхания (вдохов в минуту) и ровность ритма в реальном времени
- Доля выдохов нужной длины
- Подсказки в реальном времени: «сделайте выдох длиннее», «дышите медленнее», «не слышу дыхания»
- Итог занятия и рекомендация на следующее занятие
- Календарь занятий на неделю
- Отчёт для врача: занятия за 7 дней, личная норма, изменение одышки, динамика частоты, PDF и CSV
- Демо-режим без микрофона: сигнал дыхания смоделирован, это видно на экране

## Как это работает

1. Звук с микрофона проходит полосовой фильтр 150–2500 Гц, где слышен шум дыхания.
2. Каждые 50 мс считается энергия сигнала в логарифмической шкале с адаптивным уровнем шума.
3. Порог с гистерезисом отделяет звук дыхания от тишины.
4. Частота дыхания оценивается автокорреляцией огибающей за последние 30 секунд. Высота пика автокорреляции показывает ровность ритма.
5. Длительность выдоха сравнивается с планом упражнения, и из этого строятся подсказки.

Всё считается в браузере. Звук никуда не отправляется и не сохраняется. История занятий хранится только в localStorage этого браузера.

Сейчас это алгоритм обработки сигнала. Следующий этап — обученный классификатор фаз дыхания (вдох, выдох, пауза) на записях добровольцев.

## Запуск

Для доступа к микрофону страница должна открываться по HTTPS или с localhost.

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

Онлайн-версия работает через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Структура

- `index.html` — экраны приложения
- `styles.css` — оформление
- `i18n.js` — тексты на русском и казахском
- `breath.js` — анализ дыхания (`BreathAnalyzer`), пейсер (`Pacer`), моделированный сигнал
- `app.js` — логика экранов, подсказки, отчёт

## Важно

Wellness-инструмент под наблюдением врача. Не ставит диагноз и не заменяет лечение.
